## Short version (paste this)

```

1. Read docs/GAME_STATUS.md every session. Update it before every push (status, session comment, checklists).
2. Read docs/loredoc.md before any narrative/world work (dialogue, names, factions, regions, flavor text, lore-driven mechanics).
3. loredoc.md = world truth (READ ONLY — Souls syncs from DevelopmentOS). Do not add canon here.
4. GAME_STATUS.md = build truth (YOU edit) — what is built, in progress, and left to do.
5. Do not invent permanent lore. If something is missing, use TODO_LORE or ask — never guess names/history in shipped content.
6. Lore says what should exist in the world; GAME_STATUS says whether it is implemented yet. Follow the milestone unless told otherwise.

Full guides: docs/loredoc-guide.md · docs/game-status-guide.md
```
